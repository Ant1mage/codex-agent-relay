# Previous Relay app icon (superseded)

The tiled icon that Relay shipped before the current mark in `assets/appicon`.

It drew a light rounded-square "card" with a graphite branching mark on the
macOS 824/1024 grid. Retained only so the change can be reverted, or the tile
reused; nothing references these files.

- `relay-icon.svg` - full app icon with the card and grid margin
- `relay-icon-small.svg` - the 16/32/64px optical variant
- `relay-icon-tight.svg` - cropped mark used for in-app drawing
- `relay-icon-tile-1024.png` - a 1024px render of the tiled icon

The current mark is deliberately different: a bare, tile-less, monochrome
vector. It fills its box differently, so do not copy these coordinates.
