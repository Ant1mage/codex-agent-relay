# Relay App Icons

Canonical vector and transparent PNG assets for the Relay menu bar app and UI.

```text
svg/relay-icon.svg         dark mark for light surfaces
svg/relay-icon-dark.svg    light mark for dark surfaces
png/light/                transparent light-theme exports
png/dark/                 transparent dark-theme exports
```

Use the SVG as a CSS mask when the icon should inherit the UI color. Use the PNG
exports for platform icons and other raster-only surfaces. These assets are
checked in as deliverables; do not regenerate them as part of a build.
